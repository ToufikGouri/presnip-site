# Presnip site

The website for Presnip, a browser extension that saves text you reuse and inserts it anywhere.

Pages: home, privacy policy and contact. Built with React Router 8 (prerendered to static HTML), React 19, TypeScript and Tailwind v4, and hosted on Vercel.

```bash
npm install
npm run dev       # develop
npm run build     # static site in build/client
npm run preview   # serve the build like Vercel does
npm run check     # type check and formatting
```
